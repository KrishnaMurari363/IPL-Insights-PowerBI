# IPL-Insights-PowerBI
This project is a professional end-to-end IPL Analytics Dashboard developed using Power BI. The dashboard provides deep insights into team performance, batter intelligence, bowler analytics, venue trends, and tournament statistics across IPL seasons.

## Project Objective

The objective of this project is to transform raw IPL match-level data into actionable cricket insights using modern Business Intelligence techniques, interactive dashboards, and advanced analytical modeling.

## Dataset Information

- IPL historical ball-by-ball dataset
- Multiple IPL seasons covered
- Match-level and player-level granular data
- Includes batting, bowling, venue, and match outcome statistics

## Dashboard Pages

### Executive Overview
High-level tournament insights, venue trends, and overall IPL performance analysis.

### Team Analytics
Detailed team performance, rivalry insights, toss impact, and momentum analysis.

### Batter Analytics
Player batting intelligence including strike rate, consistency, boundaries, and scoring trends.

### Bowler Analytics
Bowling performance analysis including wickets, economy, dot-ball pressure, and bowling figures.
